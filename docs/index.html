How it works

Three commands. That’s the whole product.

  1. go2 add Save a host once — alias, user, port, key or password.
  2. go2 list See every server at a glance when you forget the names.
  3. go2 pi Land in a real SSH session. Arrow keys, resize, the lot.

Install

Clone, run the installer, reload your shell.

Works on macOS, Linux, and Windows (WSL). Needs Bash and OpenSSH 8.4+.

git clone https://github.com/knaps151/go2.git
cd go2
./install.sh
source ~/.zshrc

Then run go2 add and connect with go2 <name>.
